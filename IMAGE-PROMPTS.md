# Image prompts — Trivian AI Solutions (for ChatGPT)

**Goal:** each image shows how the service works, step by step, so a visitor understands it at a glance without reading.

**Style:** a miniature paper-craft scene: white folded paper on dark stone, with an orange light glowing from inside the folds (the same look as the trivian logo). Each step of the workflow is a recognisable paper object. The objects run **left to right** and are joined by a glowing orange trail, like data moving through the system.

**No text in the images.** Image tools misspell words. I'll put the step names on the website under each image. The "Steps shown" line under each prompt is that caption.

## How to use these in ChatGPT
1. Open a **new chat** and paste **prompt 1**. Every prompt describes the full look, so no reference image is needed.
2. Paste the next prompts **in the same chat**, one at a time, so all images keep the same paper, light and stone.
3. *(Optional, for an even closer match.)* Attach your logo file (`trivan logo .png` on your Desktop) to a prompt and add: *"Match the paper, light and colours of this image."*
4. If something is wrong, reply: *"Remove [the problem]. Keep everything else exactly the same."* For example: "Remove the text on the calendar." Or: "Make the phone look more like a phone handset."
5. Download each image and send it to me (or save it with the filename shown). I'll place it on the site with its caption.

All images are **landscape**, because workflows read left to right. Keep everything away from the edges so I can crop them.
